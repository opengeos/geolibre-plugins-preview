GeoLibre plugin previews

This site hosts throwaway preview builds of GeoLibre with a submitted plugin baked in, one per open pull request in opengeos/geolibre-plugins.

Previews live at pr-preview/pr-<N>/ and are deleted when their pull request closes. Everything here is machine-generated and disposable — nothing is served from this repository in production. The published plugin catalog is at plugins.geolibre.app.

Previews run unreviewed third-party plugin code in your browser. Open them only for pull requests you are reviewing, and prefer a throwaway browser profile.
